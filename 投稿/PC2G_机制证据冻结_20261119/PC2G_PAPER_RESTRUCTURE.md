# PC2G 论文重构方案

## 题目与核心问题

**首选题目**　跨工况故障诊断中多源伪标签质量差异及其影响研究

**备选题目**　多源监督构造对跨工况故障诊断泛化性能的影响

论文研究多源域伪标签质量怎样随有标签源域角色变化，及其怎样影响留出工况上的故障识别。PC2G 作为统一的实验框架，提供可分别控制标签来源、筛选集合及扰动一致性的训练入口。标题、摘要和引言都围绕监督构造和机制证据展开。

## 三项贡献

1. **解耦监督内容与监督覆盖。** 在同一主辅网络骨架下交叉控制硬伪标签来源与样本入选规则。利用同一条件下的配对比较，考察校正改变了哪些类别标签、哪些批内位置进入训练，以及这些改变与目标域分类表现的关系。[历史监督构造核查](../../PC2G_RESEARCH_AUDIT.md)
2. **发现同一无标签源的伪标签质量对源域角色敏感。** HUSTbearing 固定留出 80 Hz，完整比较 20、35、65 Hz 提供标签的三种角色。将有标签源从 20 Hz 换为 35 Hz 后，共享无标签源 65 Hz 的 Full+B 入选错误率由 55.957% 降至 26.181%，其中中度滚动体入选后误标正常从 96.594% 降至 0.439%。角色调整同时改变真实监督来源和其他无标签源任务，因此该结果描述角色依赖性。[角色轮换报告](../../output/pc2g_hust_role_rotation_20261118/PC2G_role_rotation_final_report.md)
3. **验证固定入选条件下替换错标的影响。** 以原监督 A 为参照，在相同 65 Hz 入选位置、批内顺序和每头损失权重下，Oracle 用源端真值替换已入选错标。80 Hz 的 Accuracy 和 Macro-F1 分别提高 6.081 和 7.053 个百分点，三个种子的两项配对差均为正。这个比较直接检验了标签内容，Oracle 的额外真值使用在图、表和摘要中均明确标识。[Oracle 预注册](../../output/pc2g_hust_65hz_oracle_preregistration_20261119/oracle_preregistration.md) · [结果及配对差](../../output/pc2g_hust_65hz_oracle_preregistration_20261119/oracle_final_report.md)

## 方法部分保持四个概念独立

| 概念 | 文中定义与报告方式 |
| --- | --- |
| 伪标签质量 | 标签与源端离线真值一致的情况。分源、分真实类别、按训练阶段报告入选后错误率、主导误标流向和相应分母。 |
| 样本筛选质量 | 筛选把监督分配给哪些出现位置。报告逐类留存率、共同入选和新增或移除位置，以及固定标签来源时两种集合的误标率。 |
| 有标签源域角色 | 哪一工况向主辅头提供真值，同时决定其他源域的无标签角色与辅助预测任务。 |
| 目标域分类边界泛化能力 | 留出工况上的分类表现，通过 Accuracy、Macro-F1、逐类 Recall、预测分布和误判流向描述。现有指标观测的是表征与分类头的合成输出。 |

将固定扰动一致性权重的标签来源记为原始或校正，将入选集合记为原始或校正。Raw 对应原标签与原集合，Label 只切换标签，Select 只切换集合，Full 同时切换。使用 Label−Raw 和 Full−Select 比较固定集合下的标签效应，使用 Select−Raw 和 Full−Label 比较固定标签下的筛选效应。标签与筛选的交互用 `(Full−Select)−(Label−Raw)` 表示。每次在相同一致性状态、任务和种子内配对，完整保留正、负及零差。[试跑配对表](../../output/pc2g_cross_dataset_pilot_20261117/paired_differences.csv) · [角色轮换完整比较](../../output/pc2g_hust_role_rotation_20261118/HUST_role_rotation_comparison.md)

### 各数据集在正文中的作用

- **C-PU 和 DIRG** 用于说明因素对照下的收益随任务与比较对象变化。历史四目标下 C-PU 的 Full+B−Raw 为 +3.610 个百分点，DIRG 对应约 +1.299 个百分点且 Label+B 均值更高。旧 C-PU 有标签源训练和验证窗口存在样本点重叠。独立归档的三类整记录协议 PU-RS3-15-v1 中，FullB−Raw 为 +0.117 个百分点，其统计范围为固定四目标与五种子。两套 C-PU 协议各自保留。[历史审查](../../PC2G_RESEARCH_AUDIT.md) · [整记录协议结果](../../output/pc2g_formal100_acceptance_20261020/完整验证结果报告.md)
- **CWRU** 作为探索性复现，固定 0 HP 有标签和 3 HP 留出。Full+B−Raw 平均 +1.333 个百分点，按同样开启一致性的 Raw+B 比较为 +0.889 个百分点，净增主要集中在正常和内圈。原采样链随健康类别绑定，归档结果可用于描述该试跑配置，无法量化这项混杂的贡献。[类别贡献表](../../output/pc2g_cross_dataset_diagnostic_20261118/CWRU_class_analysis.md) · [预处理核查](../../output/pc2g_source_diagnostic_20261118/CWRU_preprocessing_audit.md)
- **HUSTbearing** 承担机制主线。20 Hz 有标签时，A 的 65 Hz 和 35 Hz 入选错误率分别为 55.957% 和 1.766%。角色轮换显示同源质量对角色敏感，四臂结果说明关闭整条监督路径会改变混淆结构，Oracle 在冻结集合后验证了标签内容的作用。[专项诊断](../../output/pc2g_source_diagnostic_20261118/HUST_65Hz_error_analysis.md) · [路径干预报告](../../output/pc2g_hust_65hz_path_20261119/HUST_65Hz_path_intervention_report.md) · [Oracle 报告](../../output/pc2g_hust_65hz_oracle_preregistration_20261119/oracle_final_report.md)

## 摘要内容建议

多源跨工况故障诊断依赖无标签源域提供的伪监督，伪标签的内容和入选范围可能随源域角色变化。本文在同一网络骨架下分别控制伪标签来源与样本筛选集合，并通过有标签源域角色轮换和固定集合干预研究伪监督质量。HUSTbearing 固定留出 80 Hz 时，将有标签源由 20 Hz 换为 35 Hz，65 Hz 无标签源的入选错误率由 55.957% 变为 26.181%。在保持原入选轨迹及损失权重的条件下，利用 65 Hz 源端真值纠正已入选错标，目标 Accuracy 和 Macro-F1 平均分别提高 6.081 和 7.053 个百分点，三个配对种子方向一致。结果揭示了源域角色与伪标签质量之间的关系，并给出固定入选条件下标签错误影响留出工况识别的机制证据。[角色报告](../../output/pc2g_hust_role_rotation_20261118/PC2G_role_rotation_final_report.md) · [Oracle 报告](../../output/pc2g_hust_65hz_oracle_preregistration_20261119/oracle_final_report.md)

## 结论落点

跨源质量差异需要分域、分真实类和分阶段观测。角色调整能够同时改变监督来源和辅助预测任务。固定入选纠错能够改善当前任务的总体指标并增加具体故障的正确识别次数，改善幅度随种子和故障类别变化。方法主张以这些可复核的比较为限。[适用边界与投稿用表述](PC2G_LIMITATIONS.md)
