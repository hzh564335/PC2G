# HUSTbearing 35 Hz 与 65 Hz 的同口径对照

同一 20 Hz 有标签源和训练预算下，Full 在两个无标签源均选中约 54.4% 的采样出现。**35 Hz 的入选错误率为 1.766%，65 Hz 为 55.957%。** 两源合计的 301 313 次入选错误中，65 Hz 占 **96.938%**。表中每格合并三个配对优化种子的有放回采样出现，两个 B 水平的伪标签和筛选轨迹相同。[逐域归档复算](HUST_source_pseudo_label_by_domain.csv)

固定校正集合，35 Hz 的 Full 相对 Select 将 **1 752 次错改对、347 次对改错**，合计减少 **1 405 次**错误。1 397 次净改善来自前 1 000 步，中期再少 8 次，后期相同。65 Hz 的相同干预则多 1 099 次错误。若把两域直接合并，只会看到错误次数净减 306，源域之间的方向差异随之被平均掉。按损失中逐步递增的系数及每域入选分母，35 Hz 的每头错误名义系数从 68.0655 降到 52.6255，65 Hz 则从 7 131.4970 增至 7 154.2021。两域合计名义系数上升约 7.2651。两种统计量描述了不同权重下的错误监督暴露。[逐阶段和名义系数](HUST_source_pseudo_label_by_domain.csv) · [损失口径](HUST_65Hz_error_analysis.md)

35 Hz 的全样本类别预测错误由原始 41 513/960 000（4.324%）降到校正 37 605/960 000（3.917%）。校正使 35 Hz 的重度内圈伪标签占比从 10.312% 升至 10.798%，重度复合从 13.139% 降至 12.562%。65 Hz 的重度内圈占比由 13.901% 降至 13.556%，重度复合由 9.297% 升至 10.266%。每个源每类都有 81 个静态窗口，预测类别分布由辅助模型输出决定，有放回采样也会使离线真类出现次数略有不同。逐类表给出原始预测、校正预测和实际入选三种口径。[逐类比例、正确率及原文件](HUST_source_pseudo_label_by_class.csv)

本轮只有一个有标签源角色。已有对照能定位错误最集中的无标签源及类别，无法量化频率、记录特性、辅助分支位置与标签角色各自对误标的作用。
