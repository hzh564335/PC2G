# CWRU 3 HP 试跑的类别贡献

本轮 CWRU 的 +1.333 个百分点集中在正常与内圈两个类别。Full 相对 Raw 的净增由这两类各贡献 3 次正确判定。Full+B 相对 Raw 的净增更集中，内圈贡献 5 次、正常贡献 1 次。三个种子在同一批目标窗上做配对，因此这里的计数单位是“种子×窗口”的正确判定次数。

## 类别与种子的净贡献

对照中的类别指真实类别。表中每个类别的“净增窗数”是三种子的正确判定数差之和，贡献按净增窗数除以 450 再乘以 100 计算。450 为每个对照的 3×150 次评价；同一批信号窗在三种子中重复出现。滚动体和外圈在八组各个种子的召回率均为 100%，因此各自对准确率差的贡献为零，其精确率或 F1 仍可随其他真实类误入该预测类的情况改变。

| 对照 | 正常净增窗 / 贡献（pp） | 内圈净增窗 / 贡献（pp） | 种子 0 / 1 / 2 净增窗 | 平均 Accuracy 差（pp） |
|---|---:|---:|---:|---:|
| Label−Raw | +3 / +0.667 | +2 / +0.444 | +1 / +3 / +1 | +1.111 |
| Select−Raw | +1 / +0.222 | +4 / +0.889 | +2 / +2 / +1 | +1.111 |
| Full−Raw | +3 / +0.667 | +3 / +0.667 | +1 / +5 / 0 | +1.333 |
| Full+B−Raw | +1 / +0.222 | +5 / +1.111 | +3 / +2 / +1 | +1.333 |
| Label+B−Raw+B | +1 / +0.222 | +1 / +0.222 | 0 / 0 / +2 | +0.444 |
| Select+B−Raw+B | 0 / 0.000 | 0 / 0.000 | +1 / −2 / +1 | 0.000 |
| Full+B−Raw+B | +2 / +0.444 | +2 / +0.444 | +3 / −1 / +2 | +0.889 |
| Full+B−Full | −2 / −0.444 | +2 / +0.444 | +2 / −3 / +1 | 0.000 |

Label 相对 Raw 在三个种子中各多正确识别一个正常窗，另在种子 1 多正确识别两个内圈窗。Select 的净收益更偏内圈，种子 1 的内圈多正确识别 3 窗，正常则少 1 窗。Select 的正常召回平均上升 0.901 个百分点，但精确率下降 2.051 个百分点，F1 下降 0.332 个百分点。两种单因素配置的滚动体召回均维持满分，滚动体 F1 分别下降 0.889 和 0.444 个百分点。

Full 相对 Raw 的正常和内圈 F1 分别增加 2.282 和 2.024 个百分点。Full 相对 Label、Select 的平均 Accuracy 各只高 0.222 个百分点，逐种子正确判定数差分别是 `[0,+2,−1]` 和 `[−1,+3,−1]`。CWRU 的联合配置由正常和内圈的错误减少获得小幅收益，具体类别贡献随 B 的开关与对照组而变。Full+B 相对 Raw 的 5/6 净增归于内圈，换成同样开启 B 的 Raw+B 作对照，正常和内圈各贡献一半。[逐种子成绩](../pc2g_cross_dataset_pilot_20261117/seed_results.csv) · [配对差原表](../pc2g_cross_dataset_pilot_20261117/paired_differences.csv)

## Full 与 Full+B 的同均值

两组平均 Accuracy 均为 92.444%。逐窗比对有 6 次类别预测变化，构成 3 次由错到对和 3 次由对到错。下表列出了每一次变化的类型。

| 种子 | Full 正确窗 | Full+B 正确窗 | Accuracy 差（pp） | 变化窗的真实类和预测方向 |
|---:|---:|---:|---:|---|
| 0 | 133 | 135 | +1.333 | 2 个真实内圈窗由预测外圈改为内圈 |
| 1 | 140 | 137 | −2.000 | 2 个真实正常窗由预测正常改为内圈，1 个由正常改为外圈 |
| 2 | 143 | 144 | +0.667 | 1 个真实正常窗由预测内圈改为正常 |

由于正常净减 2 窗与内圈净增 2 窗抵消，B 对 Full 的平均准确率差为零。其平均 Macro-F1 差为 −0.078 个百分点。观察到的正向变化限定在一个 3 HP 目标任务和一个有标签源角色。三个优化种子只能描述这项任务的训练波动，无法确认稳定的联合收益或显著性。
