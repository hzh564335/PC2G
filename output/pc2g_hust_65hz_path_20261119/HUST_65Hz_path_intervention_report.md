## 解释范围

B−A 与 D−C 衡量整条 65 Hz 主伪标签交叉熵的净作用。该干预同时屏蔽正确和错误标签的损失，无法单独识别错标的因果贡献。C−A 与 D−B 只改变 65 Hz 对一致性损失的直接项。一致性分母为 192，三域仍一起完成干净和扰动前向，65 Hz 仍可经共享批归一化与辅助分支影响模型。固定分母和其余项的代数权重不能抵消总梯度随门控造成的变化。

本轮固定 20 Hz 提供真值。所得对比无法分解既往角色轮换差异。三个种子描述同一批窗口上的优化波动。逐种子结果仅作描述性比较。
