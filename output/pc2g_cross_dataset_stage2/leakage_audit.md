# 文件分组与窗口泄漏核验

核验范围为拟使用的 CWRU 四负载、四类子集和 HUSTbearing 四个定速、九态子集。读取器按独立原始文件切窗，窗长 3 200、步长 3 200。各任务的统计结果来自实际信号及逐文件角色，而非仅检查文件名。[可复算的核验程序](../../experiments/pc2g_cross_dataset/tasks.py) · [机器统计与角色](dataset_statistics.json)

|---|---:|---:|

**文件与角色。** 每个任务验证目标、带标签源、两个无标签源的记录 ID 两两不相交，合并后恰好覆盖全部入选记录。随着留出目标改变，同一记录在不同训练任务中可承担不同角色。只在各自独立的训练中使用对应角色。CWRU 固定用原 MAT 编号匹配驱动端键；99.mat 附带的相邻记录通道未进入数据。HUST 读取前核对原文件与 X 通道指纹，带标题冲突的两条变速记录均在适配器层拒绝。[CWRU 清单](cwru_manifest.csv) · [HUST 清单](hust_manifest.csv)

**窗口与信号。** 对每条记录验证首窗起点为零、所有起点相差 3 200、各窗值有限且非常量。以 SHA-256 比较全窗，分别检查原幅值 float32 和逐窗归一化数组。针对 C-PU 曾发现的时移重叠，本次还在不同记录之间检查 0 至 3 136 点位移：用前两点定位候选，再逐点比较完整相交的后缀与前缀。CWRU 在统一到 12 kHz 后核查，HUST 在原 25.6 kHz 核查。该检验覆盖这一类精确复制；相似波形、加噪或经其他滤波后近似重合的区段不在精确匹配的判定范围。

**预处理与可见信息。** CWRU 降采样逐文件独立执行，滤波不跨文件或工况。逐窗归一化仅计算该窗的极值。训练数据入口只读取三个源文件组，只有带标签源返回标签；无标签源真实标签留在离线清单。全库完整性核验不进行模型或目标表现评价。到训练阶段还须用运行回执验证每次训练的实际文件访问和目标解封顺序。

**物理重复。** HUST 发布者已确认同状态跨频率使用同一只轴承。CWRU 亦不能把多个负载下的文件视为独立设备验证。记录互斥提供跨工况、整记录留出的评价；外推至未见轴承个体需要独立的物理样本设计。[HUST 数据维护者说明](https://github.com/CHAOZHAO-1/HUSTbearing-dataset)
