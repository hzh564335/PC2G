# CWRU 与 HUSTbearing 的类别交集

两个拟议子集的四个工况均有完整共同类别。表中数量来自本次原文件读取和切窗；没有运行模型。CWRU 与 HUSTbearing 分别训练、分别评价，只在各自库内比较同一套标签。

## CWRU

选择工程历史上已下载、可核对官方编号的四类子集，四种负载分别为 0、1、2、3 HP。三类故障的人工缺陷直径都为 0.007 英寸，外圈只取 6 点钟位置。因此结论覆盖这一尺寸与方位。官方目录还提供其他尺寸和方位。每个单元格为“原始 MAT 编号 / 完整窗数”。[原始记录清单](cwru_manifest.csv) · [官方正常记录](https://engineering.case.edu/bearingdatacenter/normal-baseline-data) · [官方故障记录](https://engineering.case.edu/bearingdatacenter/12k-drive-end-bearing-fault-data)

| 负载 | 0 正常 | 1 内圈 | 2 滚动体 | 3 外圈 | 总窗数 |
|---|---:|---:|---:|---:|---:|
| 0 HP | 97 / 19 | 105 / 37 | 118 / 38 | 130 / 38 | 132 |
| 1 HP | 98 / 37 | 106 / 38 | 119 / 37 | 131 / 38 | 150 |
| 2 HP | 99 / 37 | 107 / 38 | 120 / 37 | 132 / 37 | 149 |
| 3 HP | 100 / 37 | 108 / 38 | 121 / 37 | 133 / 38 | 150 |

合计 16 条独立编号的记录、581 个窗。正常记录的原驱动端通道为 48 kHz，对整条记录作抗混叠 4 倍降采样。故障驱动端通道原为 12 kHz，直接读取。每条记录分别切取 3 200 点无重叠窗（约 0.267 秒），尾部不足一窗的数据舍弃。保留实际类频，0 HP 的正常窗数相对少，目标评价须同时报告 Accuracy、Macro-F1 和逐类结果。99.mat 另含 98.mat 的驱动端通道；已按原始编号选择 X099_DE_time。[采样率出处，附表 A1](https://doi.org/10.1016/j.ymssp.2015.04.021) · [读取与重采样代码](../../experiments/pc2g_cross_dataset/cwru.py)

## HUSTbearing

使用 CHAOZHAO-1 发布的轴承数据。官方给出九种状态和十一种工况。清单覆盖 99 项采集，包括 90 份定速和 9 份变速。拟议子集固定为电机设定频率 20、35、65、80 Hz，各有九条记录，九种状态在四个域的交集完整。旧实验使用 20、40、60、80 Hz，20 和 80 Hz 与旧实验共享采集记录。[全库记录与纳入状态](hust_manifest.csv) · [作者仓库及 2026 年 10 月 29 日采集说明](https://github.com/CHAOZHAO-1/HUSTbearing-dataset/blob/554fe1269055660c41e9011fe97b971348bdec7f/README.md)

| 类码 | 作者状态码 | 语义 | 每个选定工况的记录数 / 窗数 |
|---:|---|---|---:|
| 0 | H | 正常 | 1 / 81 |
| 1 / 2 | 0.5X_I / I | 内圈，中度 / 重度 | 各 1 / 81 |
| 3 / 4 | 0.5X_O / O | 外圈，中度 / 重度 | 各 1 / 81 |
| 5 / 6 | 0.5X_B / B | 滚动体，中度 / 重度 | 各 1 / 81 |
| 7 / 8 | 0.5X_C / C | 内外圈复合，中度 / 重度 | 各 1 / 81 |

每条记录取原生 25.6 kHz 的 X 振动通道；输入窗长、步长均为 3 200 点（0.125 秒），从首点切窗。每条有 262 144 点，产生 81 个完整窗，舍弃末尾 2 944 点。每域 729 窗，合计 36 条记录、2 916 窗。各库使用相同输入点数，各窗对应的物理时长不同。[读取代码](../../experiments/pc2g_cross_dataset/hust.py)

两份未纳入的变速记录存在文件名与载荷标题元数据冲突，分别是中度内圈和中度外圈的 0–40–0 文件。清单保留隔离状态。这两项不进入标签映射、切窗或四域划分。维护者确认同一健康状态跨速度使用同一只轴承，每个文件对应一次采集。四域任务可检验工况变化下的泛化，不能据此声称迁移到了新的轴承个体。[原数值及元数据核查](../da_b_dataset_assessment_20260914/hust_numeric_audit_v3/results.json)
