# HUSTbearing 65 Hz 监督路径四臂实验预注册方案

**版本 1.0 · 2026 年 11 月 19 日 · 待批准训练预算**

本实验检验一个具体问题。在 20 Hz 继续提供真值、35 与 65 Hz 继续作为无标签源的条件下，关闭 65 Hz 的主分类伪标签交叉熵，会怎样改变模型在 80 Hz 的表现？通过第二个开关控制 65 Hz 对一致性损失的直接贡献，检验这两个路径的影响是否相互依赖。

既有 20/35/65 Hz 有标签源角色轮换的结果和 A 臂的目标结果已经可见。本文锁定的是 **B、C、D 三个新增臂在获得结果前**的设计、对比、预算和解释口径。A 臂拟复用固定第 5 000 步的三个历史模型，复用条件见末节。[既有角色轮换证据](../pc2g_hust_role_rotation_20261118/PC2G_role_rotation_final_report.md) · [原试跑冻结协议](../pc2g_cross_dataset_pilot_20261117/protocol.json) · [65 Hz 源端错误诊断](../pc2g_source_diagnostic_20261118/HUST_65Hz_error_analysis.md)

## 1. 冻结任务与实验臂

- **工况与角色**。20 Hz 是唯一有标签源，35 和 65 Hz 是无标签源，80 Hz 原样留出。沿用原始记录清单、九类索引、窗口顺序与归一化。80 Hz 测试包含 729 个已有窗口，每类 81 个。训练过程只加载源域波形和 20 Hz 标签。35 与 65 Hz 的真值用于完成全部训练后的离线诊断。
- **随机配对**。种子固定为 0、1、2。每个种子与历史 A 使用相同的初始化、物理源域抽样顺序、每域 64 窗和扰动随机流。输入顺序始终为 20、35、65 Hz。
- **固定预算和选步**。每次 5 000 次 Adam 更新。初始学习率 0.001，沿用逆幂调度和 0.0005 权重衰减。只评估第 5 000 步模型，没有源验证选步或目标选模。四臂都生成 Full 的标签与筛选掩码，使用 128 批历史队列、相同类别先验和 0.6 的逐预测类比例。扰动一致性全局系数保留 0.1。只有下表中 65 Hz 的两项损失系数可变。[源记录清单](../pc2g_cross_dataset_stage2/hust_manifest.csv) · [历史运行入口](../../experiments/pc2g_cross_dataset/run_pilot.py)

| 实验臂 | 65 Hz 主伪标签交叉熵 | 65 Hz 对一致性损失的直接贡献 | 训练来源 |
|---|---:|---:|---|
| A | 1 | 1 | 已归档的 Full+B，3 个种子 |
| B | 0 | 1 | 新增 3 次 |
| C | 1 | 0 | 新增 3 次 |
| D | 0 | 0 | 新增 3 次 |

## 2. 损失定义与归一化控制

令 a、b 分别为上表的交叉熵和一致性开关。共同头与域特定头各自保留三个源的损失槽位。有标签源沿用 64 窗的交叉熵均值。两个无标签源分别以该源当步的入选数为分母，空集合贡献零。65 Hz 原有交叉熵均值乘 a。其余源的分母、权重与梯度定义采用 A 臂原实现，域间沿用求和。

一致性沿用 A 臂的归一化表示距离、扰动位置和停止梯度规则。每步计算三个源共 192 个原始/扰动配对距离。令 S₂₀、S₃₅、S₆₅ 分别为三个域内 64 个配对平方距离之和。四臂一致性损失均为 `(S₂₀ + S₃₅ + b × S₆₅) / 192`。

关闭 65 Hz 的一致性项时，分母保留 **192**。20 和 35 Hz 的单样本系数仍为原来的 1/192。两项开关均在原损失计算内部屏蔽 65 Hz 对应项的贡献。全部 192 窗仍用于原始与扰动前向，保留批归一化统计、扰动随机数消耗和缓冲恢复流程。65 Hz 的辅助 MMD、预测熵、标签生成和入选记录继续计算。辅助交叉熵仍只使用 20 Hz 真值。MMD 与熵权重分别为 0.5 和 0.005，主分类、正交及一致性项仍乘原调度系数 `r(t)=2/(1+exp(−10t/5000))−1`，其中 t 为更新步。[主辅损失实现](../../experiments/msdgn_distribution/train.py#L83) · [扰动及一致性实现](../../experiments/msdgn_distribution/modules.py#L69)

这个设计使未干预项的代数权重一致。关闭指定项会改变总梯度的大小和方向，模型状态也会随之变化。结果衡量的是**既有权重下屏蔽指定路径的净效应**。关闭一致性项后，65 Hz 仍可能经共享批归一化影响其他样本的表示。关闭伪标签交叉熵会同时屏蔽正确和错误标签，无法单独确认错误标签的因果贡献。B 与 D 的对照只覆盖 65 Hz 一致性项的直接贡献，无法据此估计保留该域全部无标签数据的价值。本轮固定 20 Hz 提供真实标签，也无法分解此前角色轮换的总收益。

## 3. 主次对比与证伪规则

记 A–D 为四个实验臂，先对同一种子作差，然后报告各臂三个原值与三个差值、均值、样本标准差及正向、零、负向种子数。所有目标指标按相同的 729 窗生成。报告正确窗数与支持数。Accuracy 的一个正确窗约为 0.137 个百分点，单类 Recall 的一个正确窗约为 1.235 个百分点。三个优化种子刻画固定任务中的训练波动。论文中的推断以固定任务为限。

| 优先级 | 对比 | 所检验的变化 |
|---|---|---|
| 主对比 | B−A 的 80 Hz Accuracy | 保留一致性时，关闭 65 Hz 主伪标签交叉熵的净效应 |
| 次要 | D−C | 关闭 65 Hz 一致性项时，关闭同一伪标签交叉熵的净效应 |
| 次要 | C−A、D−B | 分别在伪标签交叉熵开启与关闭的条件下，关闭 65 Hz 一致性项 |
| 次要 | (D−C)−(B−A) | 关闭伪标签交叉熵的效应随一致性开关改变的程度 |
| 补充 | D−A | 同时关闭两项的整体变化 |

**预定方向**。若 65 Hz 伪标签交叉熵在 A 的损失权重下具有净负作用，预期 B−A 为正。三个差值均正时可写成“观察到三个种子一致改善”。三个差值均负时，作为本任务中与该方向假设相反的证据。含零或方向混合时，报告原值与配对差，并将稳定改善判为未建立。三个种子下不作显著性或等效性判定。交互值描述两个条件差的变化，不能仅凭均值的符号宣称稳定协同。

**预定次指标**。对同一组对比报告 Macro-F1、九类 Recall、预测正常比例以及各真实故障被判为正常的比例。中度滚动体 Recall 是预定重点类别。报告九类完整结果，防止只呈现该类别改善。若主对比与中度滚动体或 Macro-F1 方向不一致，记录各自结果。真实类别来自与所有训练隔离的目标标签。模型训练结束后统一对新臂评估并一次性汇总，目标输出不回流至选步或参数设置。

## 4. 开跑前检查与记录

1. **绑定档案**。核对源清单、参考代码、三个 A 检查点与目标预测的指纹，以及 5 000 步、角色、种子和优化配置。A 为原有 20 Hz 有标签的 Full+B。使用独立的新实验目录保留归档引用。
2. **检验 A 等价与门控**。获批后用同一运行环境做 8 步短检。每个种子比较原 A 入口和新增 A 入口的初始化、采样、辅助标签与掩码、逐步损失、模型及优化器状态和 BN 缓冲。新增 A 调用原实现的交叉熵加法顺序和一致性整批均值。关闭一致性项时只将对应 64 个距离乘零后沿用整批均值。在同一批次及同一模型快照上，校验全开减关 CE 的损失差等于 65 Hz 两个伪标签头 CE 之和乘 r(t)。校验全开减关一致性的损失差等于 r(t)×0.1×S₆₅/192。四臂都检查干净、扰动前向各 192 窗，扰动随机数消耗和 BN 恢复次数相同。正式训练后的逐步审计也要比较同种子的采样下标、原始及校正预测和两套候选掩码。
3. **记录 5 000 步实际监督**。逐步保留原始与校正标签、两套掩码、实际用于主损失的域开关、按域入选数及日志。共同头和域特定头分别记录 35、65 Hz 的原始分域 CE、乘开关后进入总损失的 CE。分别记录两个辅助头的 20 Hz 有标签 CE。记录各源的一致性距离和、固定分母和门控后的贡献。历史 A 只有 21 步的合计损失快照，历史缺失的逐头逐源实际 CE 留空。
4. **离线错误统计**。全部训练完成后，通过源清单回溯采样窗口的真实标签。分别报告 35、65 Hz 每类入选、错误流向、错误进入每个主分类头的次数和名义权重。明确区分“生成并入选”与“实际进入损失”。在 B、D 中，65 Hz 仍有原始与校正的入选记录，主 CE 的实际错误输入次数为零。目标混淆矩阵以固定检查点的保存预测独立复算。
5. **异常规则**。保存失败日志，不按准确率排除种子、选择其他检查点或改超参数。若发现档案无法绑定、等价短检失败或目标边界有误，暂停正式训练，明确原因与预算影响。基础设施中断保留现场和日志，修复后按原配置继续或重新完成原实验单元，所有额外完整重跑计入实际预算。同一条件只保留一个用于统计的有效完成记录。

## 5. 提交审批的预算

| 内容 | 拟使用的预算 | 依据 |
|---|---:|---|
| 历史 A | 复用 3 个第 5 000 步模型 | 20 Hz 有标签的原 Full+B，种子 0、1、2 |
| B、C、D | **新增 9 次完整训练，共 45 000 步** | 3 个干预臂 × 3 个种子 |
| 等价和门控短检 | 最多 120 次更新 | 每个种子短检旧 A 与新 A/B/C/D，各 8 步。这些产物不进入目标评价 |
| 新臂目标评价 | 9 个固定末步检查点 | 同一批 80 Hz 窗，历史 A 使用保存预测 |
| 训练时间估算 | **约 80–100 分钟单卡** | 历史 A 三个种子每次约 8.68–8.71 分钟。四臂保持完整双前向，预留记录与核验开销 |

预算按 A 可通过等价检查计算。如果 A 最终无法证明可比，先停下说明差异。补做三个 A 完整模型属于额外预算，须另行报审。落地结果应包含冻结协议、训练和配对审计、四臂逐种子指标、逐类召回与混淆矩阵、源监督分项和按上述主次对比编写的报告。本轮提交预注册方案与预算，尚未注册到外部平台或启动训练。
